# 8.10 Return, Recurrence and Periodicity

Ordinary language compresses several distinct concepts. We keep them separate.

| **Concept** | **Minimal criterion** | **What it does not yet imply** |
| --- | --- | --- |
| Persistence | The identity criterion remains satisfied through admissible transformation | Departure or recurrence |
| Return | One nontrivial departure followed by identity-class re-entry | Repeated return |
| Recurrence | Return occurs more than once | Equal interval between returns |
| Exact repetition | A later configuration reproduces the complete tested state | That exact repetition is generic |
| Periodicity | Recurrence with a stable metric interval | Not available before physical time is earned |

A useful nesting is:

▪ exact repetition ⊂ recurrence ⊂ return-capable organization

Periodicity remains outside this nesting until metric temporal intervals are available. A return count may be a logical or external simulation index; a period requires a physical measure of duration.
