# 8.14 Retained Consequence Is Not Yet Memory

If a returned realization differs from its antecedent because of the route by which it returned, the sequence is path-dependent. Boundary made retained dependency available, and Return can now combine it with identity-class recurrence.

▪ same O<sub>F</sub> identity + different return-conditioned state = retained path consequence

The term memory should nevertheless remain deferred. A system may exhibit hysteresis or path dependence without possessing any mechanism that internally uses the retained distinction to regulate its own organization. Memory requires the stronger condition: retained change must become internally consequential to a self-maintaining system.

▪ retention ≠ path dependence ≠ memory

A crack in a rock can record a history without thereby constituting memory in any biological or cognitive sense. The distinction keeps passive retention from being read as agency.
