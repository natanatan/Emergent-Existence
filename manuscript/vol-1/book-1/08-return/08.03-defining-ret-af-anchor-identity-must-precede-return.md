# 8.3 Defining Ret(AF; ·): Anchor Identity Must Precede Return

Orientation used Ret(A<sub>F</sub>; ·) anticipatorily to express whether a directionally organized sequence can recover the same higher-order identity. Return now defines that predicate explicitly.

▪ O<sub>F</sub> = \[Σ\]<sub>~F</sub>

F denotes the identity-relevant organization by which multiple realizations count as the same higher-order identity O<sub>F</sub>. Closure adds the reference-bearing role A<sub>F</sub> when that identity becomes dynamically persistent and representative-independently addressable. Return inherits both the criterion and that earned reference role.

▪ Ret(A<sub>F</sub>; Σ<sub>k</sub>) = 1 iff Σ<sub>k</sub> ∈ O<sub>F</sub> after genuine departure

This definition must not be tuned after the trajectory is known. A defensible return test fixes F independently, permits nontrivial transformation, determines whether the sequence genuinely leaves O<sub>F</sub> while F remains applicable, and then asks whether a resultant configuration re-enters that same identity class.

Closure already introduced lumpability as an analogy for higher-order addressability (6.12). Fine-grained states may be aggregated into macro-states while preserving the relevant transition structure under specified conditions. That comparison remains useful here, but it is inherited rather than newly introduced.

▪ The return predicate is defined, not posited: Ret(A<sub>F</sub>; ·) abbreviates conditions on previously earned structure. Open question: the weakest non-circular F that makes return objective rather than observer-imposed (Question 1).
