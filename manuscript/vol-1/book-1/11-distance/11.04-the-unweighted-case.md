# 11.4 The Unweighted Case

Begin with the cheapest case. Suppose every relation contributing to a chain is equivalent under the relevant comparison standard. Then the chain contains repeated instances of the same admissible relational step.

Let u denote that reusable relational standard, lettered to stay clear of the coarse-graining standard s of 10.20. For a chain containing n such relations:

▪ L<sub>u</sub>(κ) = n u

This is the first candidate for the magnitude of relational separation. The underlying statement is that one chain contains more, fewer, or the same number of equivalent mediating relations as another. Numerical notation compresses that earned comparison.

▪ equal relational steps + cardinal magnitude ⇝ chain magnitude
