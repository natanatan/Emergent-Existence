# 14.21 Comparison Class: Logical Time

Distributed computing offers a second comparison class. Logical clocks order events by dependency among messages and processes even when no single global clock is available. This demonstrates, in a non-foundational setting, that useful order can be reconstructed from dependency relations without presupposing one universal time coordinate.

Again, analogy is not derivation. Computer processes already exist in physical time, and their communication delays are physical. The relevance is formal: dependency can carry order information that a total clock variable need not supply. The framework borrows no physical conclusion from the analogy.

The comparison sharpens a criterion for Time: if the relational substrate supports only arbitrary labels but no dependency-recoverable order, it has not earned even logical-time-like structure. If it does support such order, the next question is whether physical temporal metrics can arise from that order endogenously.
