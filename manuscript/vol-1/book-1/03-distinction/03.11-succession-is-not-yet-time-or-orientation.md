# 3.11 Succession Is Not Yet Time or Orientation

Each ordered pair in 𝒰 says that one configuration may be followed by another. This is genuine step order, and the book should not hide it. What it does not supply is a physical temporal interval or a globally oriented relation.

The relation as a whole remains exchange-symmetric: whenever (a,b) is admissible, (b,a) is admissible. Orientation later requires persistent non-equivalence between relational roles under exchange. That condition is absent here.

Likewise, an index used to display repeated application of 𝒰 records derivational or compositional order only. Time must still earn when such ordered dependence deserves a physical temporal interpretation.
