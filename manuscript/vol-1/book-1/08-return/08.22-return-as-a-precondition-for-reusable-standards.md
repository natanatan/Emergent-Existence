# 8.22 Return as a Precondition for Reusable Standards

Why should Return precede Scale? Because measurement requires re-identifiable reference structure. A ruler that irreversibly changes with every comparison is a poor standard. A clock that cannot reinstantiate a comparable state cannot mark repeated intervals. Before meters and seconds can be defined, a framework needs structures capable of serving again as the same reference in the relevant sense.

▪ stable identity + repeatable return ⇝ reusable relational reference

Return does not itself create a unit. It makes unit-like reuse conceivable. Formalism must first determine which comparisons are legitimate. Scale can then ask whether recurring relational structures establish endogenous standards without importing an external metric.
