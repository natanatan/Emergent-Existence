# 4.21 Minimal Worked Example

Start with the reciprocal Distinction from Chapter 3. Let T<sub>p</sub> map a ↦ a′ and b ↦ b′, and let W resolve a′ from b′. Then Pres<sub>W</sub>(a,b;T<sub>p</sub>) holds, so the distinction has a retained realization r<sub>ab</sub>. Let T<sub>c</sub> send both a and b to q. Then Pres<sub>W</sub>(a,b;T<sub>c</sub>) fails.

Now suppose a later configuration Σ<sub>b</sub> is admissible only when the retained difference represented by r<sub>ab</sub> is present. Removing that retained consequence changes 𝒫(Σ<sub>b</sub>). The framework may then write Σ<sub>a</sub> ≺ Σ<sub>b</sub> without saying that Σ<sub>a</sub> occurred earlier in physical time.

If multiple later configurations satisfy the same structural criterion F despite token changes, they may be grouped as O=\[Σ\]<sub>~F</sub>. None of these moves requires Ω as an anchor. The example therefore displays the complete Boundary inheritance needed downstream: resolution, retention, possibility, dependency, and criterion-based identity.
