# Appendix B. Conceptual Lexicon

The terms below carry technical senses narrower than their ordinary ones. Where a word is doing work the framework has earned, this is what it means; Appendix A carries the symbols.

| **Term** | **Symbol** | **Definition** | **First appears** | **Status** |
| --- | --- | --- | --- | --- |
| Origin | Ω, Ω<sub>n</sub> | The minimally resolved reference condition: a condition from which no operative distinction is available within the framework’s initial relational frame. Undifferentiated at that resolution; not defined as the absolute ontological absence of distinction. Not a place, moment, substance or cause. Successive origins in the recursive cycle are indexed Ω<sub>n</sub> | Origin | Defined term |
| Distinction | 𝒟 | The primitive operation that produces difference, so that one relational state differs from another. Distinction is primitive; a derivative measures change in distinction | Distinction | Working axiom (Proposition 1B) |
| Retained distinction | none | Distinguishability that survives transformation long enough to constrain later states | Preface; Distinction | Defined term (Proposition 1A) |
| Relational bit | r<sub>ij</sub> | The smallest persistent unit of relational distinction between states i and j. Distinct from the computational bit b, an engineered encoding of distinction, written b = Π(r) | Distinction to Boundary | Defined term |
| Boundary | none | The relational condition under which two states remain non-equivalent, a criterion of separability rather than a spatial surface; symmetric in the states even though the designation marking one of them as Ω is not | Boundary | Working definition |
| Higher-order membership | M<sub>ℛ</sub> | A relation r belongs to the organization ℛ exactly when embedding it there changes its admissible possibilities, 𝒫(r given ℛ) ≠ 𝒫(r). Not a new primitive: quantification over members stays in the metalanguage, and 𝒜 survives only as notation for it. Threshold and weighted membership are deferred until magnitude is earned | Relation | Convention (∃/∀ Derived; threshold Deferred) |
| Relational profile | λ<sub>i</sub>, λ<sub>F</sub>(O) | The ordered collection of retained relations a state-position (or, relative to a frame F, an object) participates in; two positions with different profiles are structurally distinguishable without intrinsic properties | Relation | Working definition |
| Relational structure | ℛ, R = \[r<sub>ij</sub>\] | A set of retained relations whose admissible states are constrained by the organization of the other relations in the set, 𝒫(r<sub>ij</sub> / ℛ) ≠ 𝒫(r<sub>ij</sub>); stronger than coexistence or connectivity | Relation | Working definition (Provisional) |
| Structural persistence | F(T(Σ)) = F(Σ), T in 𝔗 | Preservation of an identity-relevant relational invariant F through an explicitly stated class 𝔗 of admissible transformations; distinct from state persistence and from carrier persistence | Relation | Working definition |
| Relational re-instantiation | ~<sub>F</sub> | The production of a new state or realization whose organization preserves selected relational invariants of an earlier structured state; ~<sub>F</sub> is equivalence with respect to the invariant F, never physical identity | Relation | Defined term |
| Relational position | p<sub>A</sub> = λ<sub>F</sub>(O<sub>A</sub>) | The distinctive relational profile an object occupies relative to a persistent reference frame; not a coordinate, and carrying no order, interval, metric or adjacency | Relation | Working definition (Provisional) |
| Relational degrees of variation | d<sub>R</sub> | The number of independent ways a relational domain can vary; relation count is not relational dimension, and d<sub>R</sub> is not yet rank, which Formalism must earn | Relation | Working definition (Deferred formalism) |
| Information | I | What distinction becomes when preserved: preserved distinguishability, not by default a separate substance | Boundary | Working definition (Proposition 2) |
| Memory | μ<sub>i</sub> (depth) | Retained change that becomes internally consequential for a self-maintaining system: retained distinctions from the system’s own transformations alter its available responses. Requires self-maintenance, not a self-model or self-awareness. Distinct from retention, dependency order and path dependence (Boundary to Closure), which are foundational and are not yet memory | Memory | Working definition (Proposition 3B) |
| Relation | R<sub>ij</sub>, ℛ | A persistent distinction viewed as linking the states it distinguishes. R<sub>ij</sub> is the pairwise relational matrix and ℛ the relational set {q<sub>i</sub>, R<sub>ij</sub>} | Relation | Working definition |
| Recursion | ρ<sub>i</sub> (depth) | The process in which prior relational states become inputs to later ones, summarized Ω<sub>n</sub> ⇝ 𝒟 ⇝ I ⇝ ℛ ⇝ Ω<sub>n+1</sub> | Closure, Scale | Working definition |
| Closure | Closed<sub>F</sub>(ℛ) | A relational domain is structurally closed with respect to an invariant F when every dependency constitutively required to maintain F is supplied within it, the constitutive relations actually participate in maintaining F, and the requirements are jointly realizable (6.4). Structural closure is a property of a state; dynamic closure adds persistence, the preservation of that sufficiency under 𝒰 (6.7), and robust closure adds survival across a preregistered class 𝔗 (6.8). A predicate, not an operator, and not isolation from an environment. Simplicial completion (a tetrahedron, whose edge graph is K4) is one possible later mathematical realization of structure, not the meaning of closure; the earlier K4 definition is superseded (6.1) | Closure | Working definition (Provisional) |
| Comparative magnitude | A ~# B; A ↪ B; Cmp(X, Y) | Sameness of amount by bijection, order of amount by injection, and the comparative relation between two organizations. Earned before any numeral: A ~# B is not an alias for equal cardinal labels, since the label names the class the correspondence established | Scale | Working definition (Retained) |
| Endogenous standard | Cmp(O<sub>n+1</sub>, O<sub>n</sub>) ≈ Cmp\* | A comparative relation the structure supplies repeatedly through recurrence, rather than one imported from outside. Not a unit: a unit needs a calibration scheme later chapters must earn | Scale (Return) | Working definition (Provisional) |
| Scale-relative coarse-graining | CG<sub>s</sub> : 𝒞 → 𝒞 / ≈<sub>s</sub> | Reduction of detail indexed to an earned comparison standards, admissible only in that order: magnitude, then standard, then scale-relative equivalence, then the operator. Smallness by metric distance remains unavailable | Scale (deferred here by Orientation) | Working definition (Provisional) |
| Formal core | 𝔊 = (𝒞, ℜ, 𝒰) | The weakest carrier in which the earned ontology can be stated: admissible configurations, the family of earned relations at unrestricted arity, and the admissible transition relation 𝒰 ⊆ 𝒞 × 𝒞. Closure, orientation and return are predicates over it, not components of it. Compatible with graphs, hypergraphs, transition systems and other faithful representations; identical with none of them | Formalism | Working definition (Provisional) |
| Quotient dynamics | \[Σ\]<sub>F</sub> 𝒰̄ \[Σ′\]<sub>F</sub> | Transition descending to identity classes. When an independently constrained equivalence is compatible with admissible transformation, the higher-order identity supports dynamics independent of the choice of lower-order representative. Sufficient for higher-order autonomy; not claimed necessary for every emergent phenomenon | Formalism (6.12) | Working definition (Provisional) |
| Identity-class fixed point | T̄(\[Σ\]<sub>F</sub>) = \[Σ\]<sub>F</sub> | A macro-identity preserved while the lower-order state changes; distinct from an exact fixed point T(Σ) = Σ. Attractor and invariant-set language is deferred, since it presupposes topology or metric neighborhoods | Formalism | Working definition |
| Return | Ret(A<sub>F</sub>; ·) | Departure from an independently specified identity class, oriented transformation, and re-entry into that class: Ret(A<sub>F</sub>; Σ<sub>k</sub>) = 1 iff Σ<sub>k</sub> ∈ O<sub>F</sub> after genuine departure. A predicate over earned relations, not a new operation. Return of identity does not require exact repetition of state; persistence without departure is not return; and departure requires F to remain applicable, since a configuration to which F<sub>A</sub> no longer applies has dissolved rather than departed (8.4). “Origin” in the chapter title means the anchor, not Ω | Return (Orientation uses it in anticipation) | Working definition (Provisional) |
| Identity domain | Dom<sub>F</sub> | The set of configurations satisfying a closed identity’s criterion F, the members of O<sub>F</sub>. Deliberately weaker than a basin of attraction, which would presuppose state-space structure the framework has not earned | Return | Working definition |
| Retained path consequence | χ(A′) ≠ χ(A) | Difference in internal condition, not constitutive of F, left behind by the route through which an identity returned. Distinct from retention (Boundary) and from memory, which requires internal consequence for a self-maintaining system (Memory) | Return | Working definition |
| Orientation | K<sub>ij</sub> ≁ K<sub>ji</sub>, ≺ₒ | Persistent, consequential non-equivalence between otherwise exchangeable relational dependency roles. Derived, not primitive: an arrow is notation applied once the non-equivalence is established. Not partial order, causality, metric time or spatial direction (7.13) | Orientation | Working definition (Provisional) |
| Effective asymmetry | W⁽ᴸ⁾(Σ) ≠ W⁽ᴸ⁾(gΣ) | A lower-order non-equivalence that survives a higher-order identity’s resolving criterion and changes its admissible organization. Distinct from latent asymmetry, which stays below that threshold, and from orientation, which additionally persists into dependency structure | Orientation | Working definition |
| Relational irreversibility | Ret(A<sub>F</sub>; 𝔒) = 1, Ret(A<sub>F</sub>; 𝔒⁻¹) = 0 | Anchor-relative: reversing the orientational dependencies destroys, changes or redirects return to the same identity anchor. Not thermodynamic irreversibility and not an arrow of physical time | Orientation | Working definition (Speculative extension) |
| Higher-order origin | O^(n) | A closed, relationally addressable organization taken as a new starting unit for further relational construction, ℛ^(0) ⇝ O^(1) ⇝ ℛ^(1) ⇝ …; the superscript marks organizational level, not scale or time. Does not replace Ω or by itself relocate the anchor | Closure | Working definition (Provisional) |
| Constitutive dependency | none | A dependency without which the identity-relevant organization F is not specified or maintained; contrasted with an enabling condition, an input the organization operates under without being constituted by it. Closure requires every constitutive dependency to be internal, not every input | Closure | Working definition |
| Relational addressability | Ē(\[Σ\]<sub>~F</sub>) = \[E(Σ)\]<sub>~F′</sub> | The condition under which a closed organization enters higher-order relations as one relatum: an external relation E is well defined on the equivalence class O<sub>F</sub> exactly when Σ<sub>a</sub> ~<sub>F</sub> Σ<sub>b</sub> implies E(Σ<sub>a</sub>) ~<sub>F</sub>′ E(Σ<sub>b</sub>), so that E descends to the class, as in a quotient construction or a lumpable Markov chain. The sense in which completion becomes a new origin; not yet causal addressability | Closure | Working definition (Provisional) |
| Substrate | 𝔖 | The evolving totality of relational structure from which effective geometry is projected. The preferred parsimonious reading treats it as the structure itself and not a medium beneath it | Formalism | Working definition (Open in the Register) |
| Metarelation | none | A relation among relations, the basis of the deeper state space treated in Formalism | Formalism | Working definition |
| Ontological distance | d<sub>O</sub>(A,B) | A vector (d<sub>P</sub>, d<sub>I</sub>) of physical or spatiotemporal distance and informational or relational distance. Distinct from the correlation-based emergent distance d<sub>ij</sub> = −l<sub>0</sub> ln(/C<sub>ij</sub>//C<sub>0</sub>) | Formalism, Distance | Working definition (Proposition 10) |
| Reference frame | 𝒻<sub>i</sub>, W<sub>i</sub> | A stable entity treated as a local filter of a larger relational reality, with weighting operator W<sub>i</sub> so that experienced reality O<sub>i</sub> = W<sub>i</sub>(X) | Boundary (concept); Vol II | Working definition |
| Projection | Π, P^A<sub>m</sub> | A map from relational structure to effective spacetime coordinates or fields, Π: M<sub>rel</sub> → M^(3,1), with components P^A<sub>m</sub> | Space | Working definition (Proposition 6) |
| Coarse-graining | CG\[·\] | Averaging over microscopic relational structure to give an effective description; g<sub>mn</sub> = CG\[G<sub>AB</sub>\] is the shorthand | Space to Gravity | Working definition |
| Epistemic mode | none | The kind of claim a passage makes: Observed, Established, Interpretive, Speculative, Predictive or Formal (Normative in Volume III) | Preface | Defined term |
