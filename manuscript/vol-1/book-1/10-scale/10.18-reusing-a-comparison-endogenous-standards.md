# 10.18 Reusing a Comparison: Endogenous Standards

Closure and Return earned a reusable higher-order reference structure: O<sub>F</sub> can survive realization change, function through A<sub>F</sub> as an organizational reference, depart from its identity condition, and later become addressable as that identity again. None of this yet provides a quantitative standard. Reuse becomes a scale standard only when the same comparison relation can be re-instantiated across organizations or levels.

Now a returned or re-instantiated identity can take part in comparison. If the same comparative relation can be reconstructed each time, it becomes an endogenous standard:

▪ Cmp(O<sub>n+1</sub>, O<sub>n</sub>) ≈ Cmp\* whenever the identity recurs

The standard is endogenous because nothing is carried in from outside: the structure supplies the relation repeatedly. This is still not a metre or a second. It is the more primitive achievement that makes a calibrated unit conceivable later.

▪ return ⇝ reusable identity ⇝ reusable comparison ⇝ endogenous scale

▪ Re-instantiable comparison can supply an endogenous standard without an external unit. Closure and Return provide reusable identity and reference; Scale adds repeatable magnitude comparison.
