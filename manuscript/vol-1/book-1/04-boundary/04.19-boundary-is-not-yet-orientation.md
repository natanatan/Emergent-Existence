# 4.19 Boundary Is Not Yet Orientation

The retained distinction remains exchange-symmetric. Dependency precedence ≺ is a relation between configurations connected by retained consequence; it does not assign source/target roles inside the primitive dyad or establish the orientational non-equivalence later written ≺ₒ.

Orientation must still earn persistent consequential non-equivalence between otherwise exchangeable roles. Boundary gives it retained structure to work with, not the result in advance.
