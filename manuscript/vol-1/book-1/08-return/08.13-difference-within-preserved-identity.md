# 8.13 Difference Within Preserved Identity

Before Return, difference most naturally separated one state or organization from another. Non-identical return introduces a further possibility:

▪ difference can accumulate within an equivalence class

We can now separate the question “does this configuration belong to O<sub>F</sub>?” from “in what internal condition is this realization?” That separation is structurally important because later theories routinely distinguish stable identity from internal state. None of those later interpretations is yet derived.
