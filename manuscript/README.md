# Manuscript

One Markdown file per section, grouped by volume, book and chapter.

```
manuscript/
  vol-1/
    book-1/            Existence: Origin to physical reality
      00-front/        How to read, Preface, Introduction, Methodology
      01-origin/       one file per section: 01.01-looking-back-from-now.md …
      …
      14-time/
      90-back/         Appendices, ledgers, list of figures
    book-2/            Spacetime toward life
  vol-2/               Life to consciousness
  vol-3/               Consciousness to institutions and meaning
```

Folder and file names follow the current manuscript order. That order is editorial and can change. Claim IDs never depend on it: prose cites claims as `EE-C-nnnn`, and a claim's chapter and section are recorded in the Claim Register.

The prose never states a claim's status. Status lives only in `registers/`.
