# 14.26 Objections and Replies

**Objection 1:** The symbol ≺ already means “before,” so time has been smuggled in through notation.

**Reply:** The symbol ≺ is defined operationally as retained-dependency precedence, not physical temporal precedence. The stronger ≺ₜ relation appears only after the dependency graph is reduced by mutual reachability and passes the chapter’s coherence conditions. Replacing either symbol with arbitrary relation labels would leave the formal content unchanged.

---

**Objection 2:** Any update rule presupposes time because updating is a temporal verb.

**Reply:** The ordinary-language verb is indeed dangerous. Formally, 𝒰 remains the admissible transition relation introduced in Distinction. A particular functional update map may represent it only where unique succession has separately been earned. Neither representation may contain a physical time parameter if the model is to count as deriving temporal structure.

---

**Objection 3:** A partial order is mathematical structure, not physical time.

**Reply:** Correct. A partial order alone is insufficient, and Boundary does not even supply one. The proposal is that retained dependency first yields a directed relation; mutual cycles are quotiented; one-way reachability yields a strict partial-order candidate; and only an intrinsic, recursively recoverable, frame-coherent version of that order deserves temporal interpretation. Stable recurrent measures are an additional requirement for metric time.

---

**Objection 4:** Recurrence already requires time, because a cycle means returning later.

**Reply:** At the formal level, recurrence can be defined as repeated return to comparison-equivalent relational configurations along an already earned dependency chain. What is counted is ordered transformation, not elapsed seconds. The clock interpretation appears only after repeatability and calibration are established.

---

**Objection 5:** The framework cannot explain the arrow of time.

**Reply:** This chapter does not claim to derive the thermodynamic arrow. It derives, at most, a structural dependency orientation and a record asymmetry. Entropic, cosmological, and psychological arrows remain separate problems.

---

**Objection 6:** If incomparable events exist, the framework has abandoned objective time.

**Reply:** Objective temporal structure need not be a universal total order. Modern relativistic physics already denies a frame-independent global simultaneity relation in general. The present framework goes no further than its evidence permits: shared dependency can ground shared order, while incomparable events remain unordered until additional physical structure justifies a stronger relation.

---

**Objection 7:** The proposal simply redescribes causal-set theory.

**Reply:** Causal-set theory ordinarily begins with a causal partial order as fundamental. This framework begins earlier, with retained relational consequence, and asks whether a causal order can later be earned. Causal sets are therefore a comparison class and diagnostic target, not an imported ontology.
