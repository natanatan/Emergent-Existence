# 2.4 Dyadicity Is a Primitive Cost

The framework cannot honestly claim to derive numerical two-ness from the irreflexive relation. The two-pole character is already part of Proposition 2A. This is not a defect if the project states the cost explicitly; it would be a defect only if the text pretended that ≬ somehow manufactured multiplicity from a prior numerical one.

The primitive cost is therefore not “two fully formed things.” It is weaker: a minimal dyadic structure whose poles are jointly admitted and whose only declared internal fact is their non-equivalence.

This distinction matters because a foundational ontology is not improved by hiding cardinal commitments in relational notation. The project’s parsimony test counts the dyad as a commitment and later asks whether anything weaker can do the same explanatory work.
