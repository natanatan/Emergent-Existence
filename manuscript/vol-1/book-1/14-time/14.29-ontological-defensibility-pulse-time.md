# 14.29 Ontological Defensibility Pulse: Time

> This is the chapter’s Pulse sidebar. It applies to the central proposition and is set apart from the main argument so that a reader can skip it on a first pass.

| **Pulse question** | **Applied to Time** |
| --- | --- |
| 1. Entities required | Resolvable relational update states; retained constraints or records; a dependency-precedence relation; optional recurrent comparison subsystems for metric candidates. No temporal substance and no external universal clock. |
| 2. Ontological level | Higher-order organization of retained transformation. Temporal order belongs to stable dependency among changes rather than to primitive relation itself. |
| 3. Lower-order dependencies | Distinction, Boundary, Relation, Closure, Orientation, Return, Formalism, Scale, Distance, Geometry and Space—especially retained consequence, admissible possibility structure 𝒫, and Boundary’s deliberately weak dependency relation ≺. |
| 4. New emergent properties | Mutual-dependency cycle classes, a strict partial-order candidate ≺ₜ on their quotient, dependency-incomparability, recoverable record orientation, and possibly endogenous temporal standards through recurrent comparison. |
| 5. Claim types | Formal and relational at the dependency-order level; functional and conditional at the clock/metric level; interpretive where the structure is called temporal; speculative wherever later physical spacetime behavior is anticipated. |
| 6. New primitives | Ideally none. ≺ is inherited from Boundary; ≺ₜ is derived from reachability after mutual cycles are quotiented. The principal danger is an update realization, iteration variable, acyclicity condition, or recurrence criterion that already contains external time. |
| 7. Fewer assumptions? | Strengthened by not assuming raw ≺ is transitive or acyclic. Strongest if temporal order survives index removal, cycle quotienting, coarse-graining, and heterogeneous-frame recovery, and metric standards arise from independently recurrent subsystems. |
| 8. Observational constraints | The eight diagnostics of 14.25, followed in Book II by the stronger requirement that the resulting structure support empirically adequate relativistic spacetime without importing Lorentzian structure as a premise. |

The principal vulnerability is best stated on its own:

> Does temporal order emerge from retained dependency inside the relational organization, or has physical time been reintroduced through the update rule used to generate the states?

> If that question cannot be answered, the chapter has not earned Time.
