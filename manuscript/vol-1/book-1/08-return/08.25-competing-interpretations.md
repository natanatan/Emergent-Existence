# 8.25 Competing Interpretations

Dynamical. Return is recurrence in a state space. This will likely become mathematically productive after Formalism.

Topological. Return resembles loop closure. This may later motivate homotopy, winding or cyclic invariants, but no topological loop is yet part of the ontology.

Information-theoretic. Return restores an identity-relevant macrostate after transformation. Lumpability and coarse-graining provide useful later formalisms.

Organizational. Return is a higher-order relational address being restored. This is the preferred reading, because it uses only identity, orientation, transformation and equivalence structures already available.

▪ preferred definition: relational re-entry into an independently specified identity class
