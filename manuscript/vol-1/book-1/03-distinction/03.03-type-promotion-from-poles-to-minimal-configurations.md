# 3.3 Type Promotion: From Poles to Minimal Configurations

Introducing 𝒰 changes the type of the objects it relates. Chapter 2 deliberately did not treat a and b as configurations. Chapter 3 now collects them into the least carrier on which a transition relation can be defined:

▪ 𝒞<sub>𝔇</sub> = {a, b}

The move is explicit. The primitive poles now function as the minimal configurations available to the emerging update structure. This is not a claim that they are physical states in spacetime; it is a formal role required by succession.

The update relation is typed as:

▪ 𝒰 ⊆ 𝒞<sub>𝔇</sub> × 𝒞<sub>𝔇</sub>

This keeps the later Formalism chapter’s ontology honest from the start: 𝒰 is fundamentally a relation on configurations. Functional notation becomes available only where the relation happens to assign a unique successor.
