# 8.15 Return Without Physical Time

The strongest intuitive objection is immediate: return sounds temporal. A configuration satisfies F, departs from O<sub>F</sub>, and a later dependency state again satisfies F. If physical time has not been derived, has the chapter smuggled it in through ordinary grammar?

The answer depends on whether dependency order can be specified without metric duration. Boundary already supplies retained-dependency precedence:

▪ Σ<sub>a</sub> ≺ Σ<sub>b</sub>

The claim is only that the admissibility or organization of Σ<sub>b</sub> depends on retained consequence inherited from Σ<sub>a</sub>. The relation assigns no real-valued coordinate t, no duration Δt, and no rate of change.

▪ return requires ordered dependency; return does not yet require metric time

A mathematical proof or recursive definition offers a limited analogy. One proposition may depend on another. A recursive evaluation may re-enter a previously defined type, without the logical order itself being a physical clock. Computation on a real machine takes time; the formal dependency relation need not be defined by that duration.
