# 4.10 The Admissible-Possibility Set 𝒫

Retention becomes consequential only if it can restrict what remains structurally admissible. Boundary therefore restores the possibility function needed throughout Relation and later Time. For a configuration Σ, let 𝒫(Σ) denote the set of configurations reachable from Σ through the admissible succession structure available at that stage.

𝒫(Σ) = {Σ′ : Σ′ is reachable from Σ under admissible succession}

𝒫 is a set-valued possibility function, not a probability distribution. It assigns no likelihoods and assumes no measure. Where a relation r is embedded in a larger domain, 𝒫(Σ,r) may be used schematically to denote the admissible set conditional on retaining that relation.

At the primitive two-state level the set is nearly trivial. Its importance is type-theoretic: the framework now has a place to state whether retaining a distinction changes what can follow once larger structures exist.
