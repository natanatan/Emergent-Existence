# 8.21 Pre-Phase, Winding and What Return Makes Possible

▬ SPECULATIVE

Non-identical recurrence creates a structural precursor to phase. If A₀ and A₁ satisfy the same identity invariant but differ in an internal relational variable, we have separated anchor identity from condition within the anchor:

▪ A₀ ~<sub>F</sub> A₁ while χ(A₀) ≠ χ(A₁)

Physical phase normally requires a parameterized cycle, algebraic structure and often metric time or angle. None is yet available. Return supplies only the prerequisite distinction. Two realizations can occupy the same recurring identity class while differing systematically in internal condition. Repeated returns may later admit a count n or a winding index if Formalism earns the appropriate algebra and topology. For now n can function only as an external derivational or simulation index.
