# 8.5 Minimal Formal Conditions for Return

A candidate minimal definition can now be stated without metric time or geometry.

Anchor identity: an independently constrained identity class O<sub>F</sub> exists and functions in the Closure-earned reference role A<sub>F</sub>.

Oriented transformation: admissible orientational dependencies generate a nontrivial sequence from a realization of O<sub>F</sub>.

Departure: at least one intermediate configuration lies outside O<sub>F</sub> while F remains applicable to it (8.4).

Re-entry: a resultant configuration Σ<sub>R</sub> again lies inside O<sub>F</sub>.

▪ Ret(A<sub>F</sub>; ·) = departure from O<sub>F</sub> ∧ oriented transformation ∧ re-entry into O<sub>F</sub>

The expression is schematic conjunction, not arithmetic. No magnitude has yet been assigned to departure, transformation or re-entry.

This definition closes the dependency Orientation left explicit. Section 7.7 defined the persistence threshold for orientation as the minimum retention required for an asymmetry to remain consequential to later identity re-entry. Return now strengthens that re-satisfaction condition by requiring genuine departure before re-entry. No backward primitive is introduced.

▪ Return decomposes into four conditions on already-earned structure. Open question: whether orientation is necessary for return or merely one sufficient route (Question 2).
