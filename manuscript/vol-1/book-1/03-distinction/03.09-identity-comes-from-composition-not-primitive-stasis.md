# 3.9 Identity Comes From Composition, Not Primitive Stasis

Applying the derived reciprocal map twice returns the same configuration:

▪ J<sub>𝒰</sub>² = id

The identity map id is therefore generated by composition. It is not a primitive self-loop in 𝒰<sub>min</sub>. The update relation itself contains neither (a,a) nor (b,b). This matters because adding those pairs would introduce optional stasis and branching at the minimum without any derivational need.

The algebra generated by J<sub>𝒰</sub> contains {id, J<sub>𝒰</sub>}, but that closure is derived bookkeeping over compositions of the primitive update.
