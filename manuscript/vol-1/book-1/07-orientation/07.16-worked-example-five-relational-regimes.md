# 7.16 Worked Example: Five Relational Regimes

| **Regime** | **Relational condition** | **Interpretation** |
| --- | --- | --- |
| A. Resolved symmetry | KAB ~ KBA | Roles remain exchangeable; no orientation |
| B. Latent asymmetry | A finer description differs, but W⁽ᴸ⁾(Σ) = W⁽ᴸ⁾(gΣ) | The difference lies below the relevant resolving threshold; no higher-order orientation |
| C. Effective asymmetry | W⁽ᴸ⁾(Σ) ≠ W⁽ᴸ⁾(gΣ), but the asymmetry is transient | Higher-order structure resolves a difference that does not survive to constrain return |
| D. Persistent orientation | KAB ≁ KBA, and the difference alters re-entry into O<sub>F</sub> | Derived orientation: the asymmetric dependency is persistent and consequential |
| E. Anchor-relative irreversibility | Ret(A<sub>F</sub>; 𝔒) = 1 while Ret(A<sub>F</sub>; 𝔒⁻¹) = 0 | Reversing orientation fails to recover O<sub>F</sub> relative to A<sub>F</sub>; relational irreversibility |

The point of Regime E is not an arrow of time. It establishes only that a recursive dependency organization and its reversed counterpart have different consequences for return. Return can then ask what further structure makes return itself recurrent, phase-bearing, or capable of supporting a later temporal interpretation.
