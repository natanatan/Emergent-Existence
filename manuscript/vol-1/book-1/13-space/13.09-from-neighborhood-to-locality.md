# 13.9 From Neighborhood to Locality

Geometry already supplies candidate neighborhoods. For example, N<sub>epsilon</sub>(A) = { B : d(A,B) \< epsilon }. But a geometric neighborhood does not automatically constitute physical locality. To earn locality, neighborhood structure must constrain relational accessibility.

▪ Adm(A,B) = f( L(A), L(B), Geo )

This does not require nearer to mean stronger. Nor does locality require all coupling to be strictly local. The weaker and more defensible requirement is that geometric organization systematically constrain relational accessibility.

▪ geometric neighborhood + consequential accessibility ⇝ physical locality

Quantum Graphity provides a useful comparison class because it explicitly explores models in which locality and low-dimensional geometry arise dynamically from graph structure rather than being fixed background assumptions (Konopka, Markopoulou, & Severini, 2008). That work uses a specific quantum graph ontology; it demonstrates that emergent locality is a technically meaningful research target.
