# 13.12 Spatial Distance Is Not Merely Relational Distance

▪ relational distance ≠ spatial distance

The progression is mediation burden ⇝ metric separation ⇝ geometric separation ⇝ spatial separation. Spatial distance is not a wholly new metric. It is an already-earned metric relation interpreted within coordinated physical localization.

▪ d<sub>S</sub>(A,B) = d<sub>G</sub>( L(A), L(B) )

This distinction matters because the ontology can possess distance-like structure before anything deserves to be called spatially far away.
