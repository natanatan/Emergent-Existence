# 9.25 Syntax, Semantics and the Meaning of an Arrow

Syntax is the written formal language; semantics is the relational content the symbols represent. The book therefore fixes a convention wherever an arrow-like mark could hide ontology (Appendix A.2): ⇝ marks derivational progression; ↦ marks an explicit map, coupling or update of a particular item; ≺ marks retained-dependency precedence and ≺ₒ oriented dependency; and 𝒰 itself states admissible succession. The plain → marks only a map between sets or a limit, and ⇒ marks logical implication; neither denotes dependency, orientation, coupling or time.

▪ same glyph ≠ same semantic relation

Formalism therefore requires typed notation, and a notation ledger should specify for every operator whether it denotes a relation, a function, a predicate, an equivalence, a representational sequence or an external bookkeeping device. This is not cosmetic: type ambiguity can create apparent derivations by moving illicitly between meanings.
