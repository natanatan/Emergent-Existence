# 8.20 Joint Return Is Not Yet Synchronization

Suppose two orientational modes each support recurrence. We may ask whether their return conditions coincide in dependency structure.

▪ joint return ≠ synchronous return

Synchronization requires a shared temporal metric, or at minimum a justified comparative interval structure, and Return possesses neither. The restraint matters because recurring systems are natural candidates for clocks. A clock is not created merely by writing a recurrence relation.
