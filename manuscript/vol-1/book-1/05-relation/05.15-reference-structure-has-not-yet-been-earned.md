# 5.15 Reference Structure Has Not Yet Been Earned

An integrated relational organization can contain distinctive positions without yet containing an anchor. A distinctive profile says that one position differs from another; it does not establish that any member functions as a reference for the organization as a whole. Relation therefore withholds reference architecture rather than selecting one by convenience.

A later closed organization might support a localized structural reference, a distributed reference carried by several relations, or no privileged internal reference at all. All three remain downstream possibilities; none is inherited from Ω.

The methodological constraint is stricter than mere usefulness: a reference role may be admitted only if the organization itself makes that role stable and consequential under admissible succession and declared variation. Choosing the member that makes a diagram or coordinate description easiest would add analyst-imposed asymmetry.

Closure is the first chapter capable of testing this stronger possibility because closure can convert an integrated pattern into a persistent higher-order unit. Relation therefore hands forward the problem rather than an answer.

Open question: can internal sufficiency, identity preservation, dependency structure, or representative-independent higher-order addressability make a reference role endogenous rather than stipulated?

Handoff within the derivation. Relation earns integrated organization but no anchor. Closure must determine whether completion can supply an endogenous reference role without undoing the symmetry inherited from Difference through Boundary.
