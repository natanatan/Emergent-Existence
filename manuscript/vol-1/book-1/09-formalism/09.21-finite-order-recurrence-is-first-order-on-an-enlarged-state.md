# 9.21 Finite-Order Recurrence Is First-Order on an Enlarged State

Distinction left a formal debt, using first-order update notation while noting that a recurrence can depend on several antecedent terms. Suppose x<sub>n+1</sub> = f(x<sub>n</sub>, x<sub>n−1</sub>, …, x<sub>n−k+1</sub>). Define an enlarged state X<sub>n</sub> = (x<sub>n</sub>, x<sub>n−1</sub>, …, x<sub>n−k+1</sub>). Then there is a first-order update F with X<sub>n+1</sub> = F(X<sub>n</sub>).

▪ first-order state update ≠ historical amnesia

The lesson is not that our ontology stores a literal tuple. It is that finite historical dependence can be represented by a present state whose structure carries the needed retained consequences. This is why retained state dependence in Boundary to Return does not require an infinitely long primitive memory. Formalism earns only the state-sufficiency transformation.
