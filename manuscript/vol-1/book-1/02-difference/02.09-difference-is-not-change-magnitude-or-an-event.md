# 2.9 Difference Is Not Change, Magnitude, or an Event

Difference is not written as Δ because Δ is reserved elsewhere in the manuscript for change in a quantity or structure. Nor is the relation written as a non-zero magnitude. Expressions such as Δ(a,b) ≠ 0 would smuggle in both a measure and a distinguished zero before either has been earned.

Likewise, Difference is not an event. No pole “appears after” the other. No object splits. No duration elapses. Proposition 2A states a logical-structural commitment, not a cosmological episode occurring inside already existing time.
