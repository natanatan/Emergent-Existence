# 10.6 Magnitude as a Stable Class

A single pairing is useful; something reusable is better. Formalism showed how equivalence classes stabilize identity, and the same move works for magnitude. If ~# is equinumerosity, the magnitude class of A is:

▪ \[A\]<sub>~#</sub>

Every organization in the class pairs one to one with every other. The class captures a comparative property while ignoring which particular members carry it. The parallel with identity is exact and worth seeing:

▪ object identity \[Σ\]<sub>~F</sub>; cardinal identity \[A\]<sub>~#</sub>

The first says when different realizations count as one higher-order object. The second says when different collections count as one magnitude.
