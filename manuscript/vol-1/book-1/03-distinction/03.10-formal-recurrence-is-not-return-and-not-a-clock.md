# 3.10 Formal Recurrence Is Not Return and Not a Clock

The expression J<sub>𝒰</sub>² = id can look like an oscillator, and mathematically it is a two-step recurrence. Two warnings are therefore necessary.

First, exact state repetition is not the later Return predicate. Return concerns a higher-order identity that departs from and re-enters an independently specified identity class. Here the same minimal configuration is recovered by composing a reciprocal update twice.

Second, the exponent 2 counts formal composition in the analyst’s notation. It does not yet supply physical duration or a calibrated period. Formal recurrence is weaker than clockhood.

▪ formal recurrence ≠ higher-order Return ≠ physical clock
