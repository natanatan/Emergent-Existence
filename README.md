# Emergent Existence

*What is the least we can assume, and what can be logically derived from there, that might explain how a minimal origin condition could give rise to a reality rich enough for conscious agents to collectively question both the manner and the meaning of their own existence?*

Emergent Existence is a serious academic nonfiction project exploring how increasingly complex forms of reality might emerge from the least possible starting assumptions.

## The Method

1. Minimize primitives.
2. Mark every additional assumption where it enters.
3. Separate formal consequence from physical identification.
4. State plainly where derivation ends and analogy begins.
5. Where a claim cannot yet be derived or tested, name it as a research problem rather than assert it.

At a given stage, the ontology may not use a property that stage has not earned. The registers make that rule checkable.

## Status

The registers hold Book I Beta: 249 claims, 135 hypotheses, 121 elements and 14 stage ledgers. The checks run on every change and daily; open findings are listed in the **Audit report** issue. The manuscript text is not imported yet.
