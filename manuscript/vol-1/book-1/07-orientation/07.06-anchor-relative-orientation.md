# 7.6 Anchor-Relative Orientation

Orientation becomes consequential once Closure has supplied a higher-order identity O<sub>F</sub> that can function in the organizational anchor role A<sub>F</sub>. The anchor is not itself a direction. It is an earned reference-bearing identity relative to which relational profiles and dependency consequences can be compared. Orientation arises when dependencies organized relative to that reference cease to be interchangeable.

Let F be the identity criterion defining O<sub>F</sub>, and let A<sub>F</sub> denote that closed identity functioning as the organizational anchor earned in Closure. An oriented dependency sequence may be written:

▪ A<sub>F</sub> ≺ₒ Σ₁ ≺ₒ Σ₂ ≺ₒ … ≺ₒ Σ<sub>k</sub>

The subscript o marks orientational dependency, not temporal precedence. A<sub>F</sub> supplies an endogenous reference against which the organization can later test identity-class re-entry. Closure has earned this reference role for the closed organization as a whole.

Key distinction. A<sub>F</sub> is not an orientation. It supplies an earned reference identity; orientation is the persistent consequential non-equivalence of dependency roles relative to that identity and the organization that maintains it.
