# 9.15 Fixed Points and Identity-Class Fixed Points

A fixed point of a functional transformation satisfies T(Σ) = Σ. Return’s return is more general, since a macro-identity can be preserved while the lower-order state changes.

▪ \[T(Σ)\]<sub>F</sub> = \[Σ\]<sub>~F</sub>, equivalently T̄(\[Σ\]<sub>~F</sub>) = \[Σ\]<sub>~F</sub>

Call this an identity-class fixed point, or quotient fixed point. It separates exact microscopic stasis from higher-order dynamical persistence. It may later connect to invariant sets, attractors, cycles and stability. Those notions usually presuppose topology or metric neighborhoods and are not imported here. We earn the distinction and defers attractor language.
