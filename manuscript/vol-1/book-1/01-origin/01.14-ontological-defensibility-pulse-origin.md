# 1.14 Ontological Defensibility Pulse: Origin

| **Pulse question** | **Applied to Origin** |
| --- | --- |
| Entities required | Ideally none beyond the possibility of operative distinction; provisionally represented by Ω. |
| Ontological level | Minimal pre-geometric reference condition. |
| Lower-order dependencies | None physical. The concept depends only on the possibility of resolving or failing to resolve difference. |
| New emergent property | None yet. Origin establishes a starting horizon, not a dynamical result. |
| Claim type | Interpretive and definitional, with a minimal formal notation for resolution. |
| New primitive required | Provisionally Ω. Stronger if reducible to the statement that no operative distinction is yet available. |
| Can fewer assumptions do the work? | Possibly. Eliminating entity-like language for Ω remains an explicit open route. |
| Observational constraint | Indirect. Downstream derivations must succeed without importing undeclared structure; failure constrains the starting proposal. |

> The Pulse gives Origin a deliberately modest result. We have not derived existence. We have not explained why there is something rather than nothing. We have not identified a physical first moment.

> We have established a candidate starting horizon whose commitments are thin enough for the rest of the volume to be audited against them.
