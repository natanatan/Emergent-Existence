# 8.19 Nested Return and Reference-Level Dependence

Higher-order closure immediately creates more than one possible return criterion. A lower-order component may return while a larger organization does not, or the larger organization may return while its components are replaced.

▪ Ret(A<sub>F</sub>; ·) ≠ Ret(H<sub>G</sub>; ·)

Here A<sub>F</sub> is a lower-order organizational anchor and H<sub>G</sub> is a higher-order identity/reference role that contains or depends on it. Return is therefore indexed to an organizational reference level.

A city’s transportation network can recover its functional pattern after repairs even though individual vehicles and road surfaces have changed. Conversely, a particular vehicle can return to operating condition while the network remains disrupted. The analogy illustrates nested equivalence criteria, not spatial ontology.

This multilevel dependence will matter for Scale, because recurrence can be resolvable at one organizational level and invisible at another.
