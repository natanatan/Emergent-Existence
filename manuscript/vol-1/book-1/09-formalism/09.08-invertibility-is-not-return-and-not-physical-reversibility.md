# 9.8 Invertibility Is Not Return and Not Physical Reversibility

Composition permits an inverse relation, or an inverse map in the functional case, and three ideas must not collapse together.

▪ algebraic invertibility ≠ identity-class return ≠ physical reversibility

If T has an inverse, that inverse formally recovers its input under the declared encoding. Return’s return is weaker: a later state need only re-enter the anchor’s identity class. Physical reversibility is stronger in a different direction, requiring the formal inverse to correspond to an available process. A process may therefore return without being invertible, since a many-to-one transformation can erase lower-order detail while later dynamics reconstitutes an F-equivalent identity. And an invertible map need not be traversable in both directions.

Keeping these apart prevents the irreversibility criterion of Orientation and Return from being replaced by a purely algebraic notion.
