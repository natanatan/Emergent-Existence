# Appendix C. Hypothesis Status Register

Every proposition this book leans on appears here with its status, the reason for that status, and what would resolve it. The Preface promises this register and the Methodology explains why: a gap explicitly located is worth more than a conclusion reached by hiding an assumption. A reader who wants to audit the framework rather than follow it should begin here.

The eight statuses carry the meanings used throughout:

| **Status** | **Meaning** |
| --- | --- |
| Retained | Held as part of the framework, having survived the objections raised against it |
| Provisional | Held for now, on stated conditions, and revisable if those conditions fail |
| Derived | Obtained from what earlier chapters earned, rather than assumed |
| Open | Genuinely unsettled; the book states the question and does not answer it |
| Deferred | Set aside deliberately, with the chapter that must take it up named |
| Rejected | Considered and dropped, recorded so the reasoning is not repeated |
| Speculative | Proposed beyond present evidence or derivation, and kept visible as conjecture |
| Superseded | Replaced by a better-bounded formulation, and kept so the framework’s history stays auditable |

Entries are numbered for reference only; the order is the order in which they entered the project, not an order of importance. Where an entry names a chapter, it names the reference frame rather than a position in the sequence.
