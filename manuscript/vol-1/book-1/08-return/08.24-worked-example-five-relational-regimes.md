# 8.24 Worked Example: Five Relational Regimes

| **Regime** | **Relational condition** | **Interpretation** |
| --- | --- | --- |
| A. Persistence without return | Σ₀ ~ Σ₁ ~ Σ₂; the identity criterion never fails | Stable persistence; no departure, therefore no return |
| B. Departure without return | A₀ ≺ B ≺ C ≺ D; no later state re-enters O<sub>F</sub> | Oriented transformation without recurrence |
| C. Exact repetition | A₀ ≺ B ≺ C ≺ A₁ with A₁ = A₀ under the full tested state | Strong return; a potentially brittle special case |
| D. Non-identical identity return | A₀ ≺ B ≺ C ≺ A₁; A₁ ~<sub>F</sub> A₀ but A₁ ≠ A₀ | General return with retained internal difference |
| E. Return asymmetry | Forward orientation returns; the role-reversed organization does not | A<sub>F</sub>-relative relational irreversibility, inherited from Orientation |

Regime D is the chapter’s central case. It shows why return need not collapse into either trivial persistence or exact repetition. Regime E shows how Orientation’s irreversibility criterion becomes fully interpretable once Ret(A<sub>F</sub>; ·) is defined.
