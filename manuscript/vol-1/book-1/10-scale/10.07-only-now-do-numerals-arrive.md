# 10.7 Only Now Do Numerals Arrive

With finite magnitude classes established relationally, natural-number symbols may be used as labels for them.

▪ correspondence ⇝ equinumerosity class ⇝ cardinal label

For a finite organization A, writing mag(A) = n now reads as compression. A belongs to the finite magnitude class conventionally labelled n. The numeral did not create the magnitude. It names a relation that was available first through correspondence.

This matters because earlier chapters used finite examples, indices and model sizes freely in the analyst’s metalanguage while denying them ontological force (9.23). Scale is where finite cardinal magnitude begins to belong to the modelled world rather than to the notation, and the distinction does not dissolve.

▪ external counting does not become internal magnitude because the analyst writes a number
