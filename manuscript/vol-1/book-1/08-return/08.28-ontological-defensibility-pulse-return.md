# 8.28 Ontological Defensibility Pulse: Return

> This is the chapter’s Pulse sidebar. It applies to the central proposition. It is set apart from our argument so that a reader can skip it on a first pass.

| **Pulse question** | **Applied to Return** |
| --- | --- |
| 1. Entities required | No new substance: identity classes O<sub>F</sub>, organizational anchors A<sub>F</sub>, configurations, orientation, admissible transformations, and 𝒰 |
| 2. Ontological level | Pre-geometric and pre-metric recursive organization: from oriented dependency to identity-class recurrence |
| 3. Lower-order dependencies | Difference, Distinction, retention, mutual constraint, structural persistence, closure, addressability, A<sub>F</sub>, and orientation |
| 4. New emergent properties | Re-entry into an independently specified identity class after departure, and non-identical recurrence within preserved identity |
| 5. Claim types | Formal and relational at the core; interpretive on recurrence and persistence; speculative on selection and pre-phase |
| 6. New primitives | Ideally none. Ret(A<sub>F</sub>; ·) is a predicate over already defined relations, not a new ontological operation |
| 7. Fewer assumptions? | Strengthens if return follows from generic recursive constraints, not an encoded cycle, and F is fixed independently |
| 8. Observational constraints | Test non-hardcoded return, robustness, coarse-graining dependence, reversal asymmetry, token and type, nested return |

> Return tightens the ontology only if return is genuinely decomposable into previously earned identity, transformation, orientation, departure and re-entry. If a special return operator, a hidden clock, a target cycle or a post hoc equivalence criterion must be inserted, the derivation has not succeeded.
