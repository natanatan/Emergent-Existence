# 14.18 Records, Memory, and the Structural Arrow

Retained distinction nevertheless supplies a minimal record asymmetry. If state B contains a recoverable consequence of A while A does not contain a corresponding consequence of B, then B can encode information about the dependency relation in a way A cannot encode about B under that realized chain.

▪ Record<sub>B</sub>(A) ≠ ∅ while Record<sub>A</sub>(B) = ∅ for the realized dependency chain

This can support a structural distinction resembling past-directed record access: some states contain retained traces of dependencies from which they arose. But the interpretation must remain modest. A record structure is not by itself the thermodynamic arrow of time, psychological memory, or cosmological temporal asymmetry. Those require additional mechanisms.

The important result is narrower: retention can make the dependency orientation internally recoverable. Temporal direction need not be painted onto the system from outside.
