# 8.16 What Return Adds to Orientation’s Irreversibility

Orientation introduced anchor-relative relational irreversibility in anticipatory form (7.8). Return does not derive it a second time. It supplies the explicit departure-and-re-entry semantics used by that criterion.

▪ Ret(A<sub>F</sub>; 𝔒) = 1 while Ret(A<sub>F</sub>; 𝔒⁻¹) = 0

The first states that the orientational structure 𝔒 supports departure from and re-entry into O<sub>F</sub>. The second states that reversing the relevant orientational roles fails to recover that identity. Orientation’s criterion is therefore grounded rather than promissory.

This remains weaker than thermodynamic irreversibility. Return adds semantic precision to an inherited criterion; it does not add a second irreversibility principle.
