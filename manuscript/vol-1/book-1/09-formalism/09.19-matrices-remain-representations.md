# 9.19 Matrices Remain Representations

Matrices have appeared in Distinction, Relation and Orientation. A matrix R = \[r<sub>ij</sub>\] is an indexed array recording relational information. By itself it provides no vector addition, scalar multiplication, norm, angle, determinant, eigenvalue interpretation or physical dimension.

▪ matrix notation ≠ vector-space ontology

Those structures may become legitimate later if the entries and permitted operations justify them. The rule matters because calculations will use linear-algebra software externally. A successful calculation does not retroactively grant every algebraic operation physical meaning.
