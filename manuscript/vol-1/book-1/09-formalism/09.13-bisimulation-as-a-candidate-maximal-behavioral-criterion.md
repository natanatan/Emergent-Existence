# 9.13 Bisimulation as a Candidate Maximal Behavioral Criterion

Transition-system theory supplies a mature concept for matched behavior. If one state can make a transition, a bisimilar state must be able to make a corresponding transition into a state that remains related, and conversely.

▪ a ≈ b and a 𝒰 a′ ⇒ there exists b′ with b 𝒰 b′ and a′ ≈ b′

Bisimulation is useful because it tests equivalence against future relational possibilities rather than present appearance. It should not be promoted to our definition of all object identity. Two realizations may preserve F while differing in some admissible futures.

▪ bisimulation = candidate strong behavioral equivalence, not universal identity criterion

Open question: whether higher-order identity can be constrained behaviorally without collapsing into bisimulation (Question 4).
