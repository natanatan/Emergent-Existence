# 11.21 Computational Diagnostics

Relabeling invariance. Renaming lower-order components must not change the distance.

Representation invariance. Faithful graph, hypergraph, matrix, or equivalent encodings should preserve the metric relations that matter.

Decomposition perturbation. Small changes in arbitrary descriptive partition should not radically alter distance unless those changes correspond to genuine changes in the organization.

Chain robustness. If several nearly equivalent chains exist, perturbing one should not destroy the metric globally.

Quotient compatibility. Zero-separated states or higher-order equivalent states should support well-defined distances on the quotient.

Scale consistency. Coarse-grained distances should preserve declared higher-order relations where the coarse-graining is claimed to be valid.

Symmetry test. Where symmetry is claimed, reversing admissible relational chains must preserve their magnitude.

Triangle test. Distances constructed from admissible chain composition should satisfy the triangle inequality when additivity is claimed.

Hidden-geometry control. The implementation must not encode coordinates, geometric neighborhoods, target dimensionality, or an embedding into the update rules.

Random-control comparison. Candidate relational structures should be compared with matched random organizations to test whether coherent metric structure is genuinely selected rather than trivially present in every arbitrary network.

These diagnostics constrain models. They do not by themselves show that nature instantiates the ontology.
