# 20.11 The Self-Stabilizing Path

A spatial neighborhood persists through time only if the relations constituting its state remain available across successive updates. Neighboring relations must exchange state so that each local configuration stays reconciled with the region it belongs to:

$$\text{local relational state} \rightarrow \text{neighbor update} \rightarrow \text{neighborhood reconciliation} \rightarrow \text{re-instantiated local persistence}$$

A propagating excitation enters this already active process. As its completed state is handed into neighboring relations, those neighbors are updated in ways conditioned by it. Their own subsequent updates feed back into the conditions the continuing excitation meets. Where those returning constraints support the propagating organization, the path stabilizes itself:

$$\text{direction} = \text{inherited orientation} + \text{phase continuity} + \text{neighbor reinforcement}$$

The reinforcement keeps the excitation's direction; it does not keep its width. A self-stabilizing path that held a beam together would contradict the measured spreading of 20.10. The stabilization therefore acts on the direction of the dominant path, while the envelope around it still widens at about λ/D.

The self-stabilizing path is a higher-order consequence of the same neighborhood updating that space itself requires in order to persist.
