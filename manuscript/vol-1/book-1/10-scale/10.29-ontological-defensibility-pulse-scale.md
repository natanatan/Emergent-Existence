# 10.29 Ontological Defensibility Pulse: Scale

> This is the chapter’s Pulse sidebar. It applies to the central proposition. It is set apart from our argument so that a reader can skip it on a first pass.

| **Pulse question** | **Applied to Scale** |
| --- | --- |
| 1. Entities required | No new substance: distinguishable members, correspondences between them, and the recursive composition already available |
| 2. Ontological level | Pre-metric quantitative organization: from comparison of kind to comparison of amount |
| 3. Lower-order dependencies | Distinction, retention, invariance, closure, return, quotient structure, the formal core |
| 4. New emergent properties | Cardinal comparison, proportion, a stable inter-level ratio, and a standard the structure supplies without an external unit |
| 5. Claim types | Formal at the core; interpretive on the order of discovery; speculative on self-similarity and multiple scale modes |
| 6. New primitives | None: correspondence is pairing, and pairing needs only distinguishable members |
| 7. Fewer assumptions? | Strengthened, since threshold aggregation and the coarse-graining operator both cease to need primitives of their own |
| 8. Observational constraints | The ten diagnostics of 10.25, in particular relabeling invariance and the recurrence perturbation that denies φ any privilege |
