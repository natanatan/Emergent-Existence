# 8.12 Conservative and Transformative Return

The identity-class distinction permits two qualitatively different regimes. Under conservative return, the system re-enters O<sub>F</sub> while preserving nearly all currently resolved relations, so that at the tested resolution return approaches repetition. Under transformative return, the system re-enters O<sub>F</sub> while retaining differences outside F:

▪ Σ<sub>R</sub> ~<sub>F</sub> Σ<sub>A</sub> but χ(Σ<sub>R</sub>) ≠ χ(Σ<sub>A</sub>)

The symbol χ denotes an internal condition not constitutive of F. Transformative return is the more generative case because traversal can leave a relational consequence behind while higher-order identity is restored.
