# 14.11 Counting Change Is Not Yet Measuring Time

Once ordered chains exist, one can count transitions. If a chain C contains N distinguishable retained updates between eₐ and eᵦ, then N is a legitimate structural quantity:

▪ N<sub>C</sub>(eₐ,eᵦ) = number of retained update steps along chain C

But N is not automatically duration. Two chains may contain different numbers of lower-order updates while representing the same higher-order transformation. A coarse-graining map may compress several updates into one. Different local mechanisms may reorganize relational states at different granularities. Without a standard that survives such variation, step count is resolution-dependent.

The chapter therefore distinguishes update count from temporal measure. Counting provides a candidate precursor of duration only when the counted unit is itself stable, reproducible, and relationally accessible.
